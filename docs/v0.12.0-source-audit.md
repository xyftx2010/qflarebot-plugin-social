## 2. QFlareBot SDK v5 与 Cloudflare Workers 平台能力核实

通过审查 `QFlareBot/packages/sdk/src/plugin.ts` 与 `context.ts` 确认：

1. **定时调度（Cron）**：SDK v5 **原生支持** `cron: CronMap<C>`（标准 5 段 cron，由框架统一 Cron Trigger 分发），无需独立 DO 或外部服务器即可实现每 6 小时扫描增量学习。
2. **存储资源**：`PluginContext` 提供 `ctx.db`（D1，单次免费版请求 ≤ 50 查询，强制 `{table}` 占位符与 `WITHOUT ROWID`）、`ctx.r2`、`ctx.kv`、`ctx.waitUntil`。
3. **Vectorize 与 Workers AI 绑定**：**当前 QFlareBot SDK v5 `PluginContext` 未暴露 `VECTORIZE` 或 `AI` 绑定**。因此在不修改 QFlareBot 核心源码的前提下，V0.12.0 默认采用 **D1 轻量混合检索（CJK 二元组 + 标签 + 行为 + 质量/时间加权）**；Phase 6 向量检索保留接口与设计文档，待框架提供官方绑定或管理员明确授权外部 Embedding 服务后再启用。
4. **D1 中文全文检索限制**：SQLite/D1 默认 `unicode61` 分词器不支持中文分词；采用程序预提取的 CJK 2-gram 索引字段 + 关键词/标签匹配，可在 D1 免费版内以 1–2 次查询完成高相关度检索。
5. **非 `@` 消息权限现实**：部分 QQ 群可能未开启「获取群内全部消息」权限。学习系统通过「历史语料导入」+「授权范围内在线采集」双轨运行，并在后台展示实际采集来源与覆盖率。

## 3. 技术差距与建设重点

| 差距项 | 解决方案 |
| --- | --- |
| 缺乏历史聊天记录合法导入通道 | 实现前端分块解析 + 预处理脱敏 + 后端分片入库（TXT / CSV / JSON / JSONL + 字段映射） |
| 缺乏群级风格沉淀与对话场景切分 | 实现程序化统计 + 批量 LLM 语义蒸馏 + 长期/近期双层风格档案 + 热梗/示例提取 |
| 缺乏版本隔离、评估与一键回滚 | 实现候选版本状态机（`candidate / published / frozen / rejected / archived / invalidated`）、A–E 风格实验室与数据删除联动失效 |
| 缺乏防自我退化与抗污染闭环 | 严格隔离机器人输出不入语料库，实行单成员 20% 采样上限（小群自适应）与多成员证据门槛 |
