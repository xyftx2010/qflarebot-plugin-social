# QFlareBot Social V0.12.0 — 分阶段开发与验收计划

## 阶段规划

| 阶段 | 核心交付 | 独立验收标准 |
| --- | --- | --- |
| **Phase 0：源码审查与设计** | 核实 SDK v5 能力与 Migration v5 现状，输出 6 份设计文档 | 全部约束清晰无假设，迁移版本定位为 v6 |
| **Phase 1：语料导入与质量控制** | `cleaner.ts`、`importer.ts`、`segmenter.ts`、`learning-db.ts`（Migration v6） | 支持 TXT/CSV/JSON/JSONL + 字段映射；敏感脱敏、注入过滤、机器人排除、短词上下文保留、跨来源去重、成员 ≤ 20% 采样均衡、对话窗口切分单测通过 |
| **Phase 2：风格蒸馏与版本管理** | `distiller.ts`、`scheduler.ts`（版本状态机与回滚校验） | 客观特征统计 + 批量 LLM 蒸馏 + 严格 Schema 校验；长期(70%)/近期(30%)融合；热梗证据追踪；候选版本默认不自动发布；回滚前校验删除/退出状态 |
| **Phase 3：聊天引擎集成** | `prompt-compiler.ts`、`retrieval.ts`、`pipeline.ts` 集成 | 9 层 Prompt 优先级、2000 Token 硬预算、缓存失效、D1 按需检索（0~5 条）、表达重复检测、与 Fast/Smart/Full 及多模态语音无缝兼容 |
| **Phase 4：在线增量学习** | `pipeline.ts` 异步采集 + `index.ts` `cron` 定时任务 + 租约锁/检查点 | 仅采集授权群与未退出成员；每 6 小时扫描；达 100 条触发、单批 200 条；并发锁防重入；学习失败不影响正常聊天 |
| **Phase 5：反馈与风格实验室** | `feedback.ts`、管理 API 与 `/p/social/ui/` 风格学习中心 + 实验室 | 显式反馈与独立评估集（绝不回流语料库）；A/B/C/D/E 五模式同上下文对比，展示真实 Token/耗时且不发群 |
| **Phase 6：可选向量检索（暂缓）** | 仅保留接口与文档，不创建付费资源 | 经源码审查确认当前 SDK v5 未提供 Vectorize/AI 绑定，待平台支持且 D1 检索出现实测瓶颈并获授权后再实施 |
| **Phase 7：后台完善、隐私闭环与回归** | 完整隐私删除/退出/失效链路、全量单元测试、文档同步与真群验收指南 | `typecheck`、`vitest` 全量绿灯、`npm run sync` 0 警告、历史功能零回归 |

## 风险控制

1. **生产默认保守**：`style_learning_enabled` 默认 `false`（群级授权后开启），`style_auto_publish` 默认 `false`（人工审核发布），升级后不影响现有线上群聊稳定运行。
2. **D1 行数与配额保护**：实时聊天热路径仅在 `style_learning_enabled` 且该群存在已发布档案时触发 1 次缓存/DB 读取；在线采集统一在 `ctx.waitUntil()` 异步落库；原始语料默认 30 天自动清理。
