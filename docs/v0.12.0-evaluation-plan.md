# QFlareBot Social V0.12.0 — 效果评估与防退化方案

## 1. 防自我训练退化（Anti-Model-Collapse）

- **单向语料隔离**：机器人自身发出的所有消息（`session.userId === session.botId` 或导入中标记为 bot）均被 `cleaner.ts` 强制排除，绝不进入 `{learning_corpus}`。
- **独立评估集**：机器人回复及管理员/群友显式反馈存入独立的 `{learning_feedback}`，仅用于质量评估、对比实验与人工审核参考，绝不作为群友真实语言习惯的蒸馏输入。

## 2. 独立测试切分与数据防泄漏

- 评估测试集采用**时间切分**（保留最近窗口或管理员独立输入的测试上下文）与**完整对话窗口切分**，并通过内容哈希过滤与 `{dialogue_examples}` 的近似重复，避免数据泄漏导致虚高评分。

## 3. 五模式同上下文对照实验（风格实验室）

后台 `/p/social/ui/` 提供「风格实验室」，对同一条测试对话上下文分别编译并真实调用当前配置模型，返回实际耗时、Token 与输出，**绝不发送到 QQ 群、绝不写入正式上下文/记忆/语料库**：

| 模式 | 注入层级 | 观测目的 |
| --- | --- | --- |
| **A** | 原始基础人格 | 基线对照 |
| **B** | 基础人格 + 长期风格（Stable） | 验证稳定群聊风格增益 |
| **C** | 基础人格 + 长期 + 近期风格（70%/30%） | 验证近期热点与语气贴合度 |
| **D** | 基础人格 + 双层风格 + 群内热梗 + 对话行为 | 验证场景承接与适度接梗 |
| **E** | 完整风格 + 行为 + 热梗 + RAG 对话示例 | 验证端到端 Few-shot 拟人上限 |

## 4. 核心评估指标与发布门禁

- **人工显式反馈优先**：管理员在实验室或反馈面板标记 `good / unnatural / bad / meme_fail / repetitive`；静默或消息频次不直接等同于好坏。
- **自动化硬门槛（候选版本发布前校验）**：
  1. Schema 合法性 100%；
  2. 证据覆盖率（有效语料 ≥ `style_learning_min_messages` 且独立成员数 ≥ 2，小群可由管理员手动覆盖）；
  3. 风格变化幅度与重复表达检查（无禁词、无提示词注入、无高频机械复读）；
  4. 无已删除/已退出成员数据引用。
- **默认人工审核发布**：`style_auto_publish` 默认 `false`，仅在管理员显式开启且通过上述全部门禁时才允许自动发布。
