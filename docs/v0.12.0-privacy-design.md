# QFlareBot Social V0.12.0 — 隐私、安全与数据治理设计

## 1. 授权前提与最小留存

- **默认关闭、显式授权**：全局配置 `style_learning_enabled` 默认 `false`；即便全局开启，单群也需开启学习授权（`{learning_group_settings}.authorized = 1`）才会采集在线语料或执行自动学习。
- **原始语料短期留存**：`{learning_corpus}` 默认保留 **30 天**（`style_corpus_retention_days`），定时任务自动清理过期原文，不默认永久保存全部群聊记录。
- **跨群严格隔离**：所有学习表均带 `group_id`，检索与 Prompt 编译前强制校验 `group_id` 与授权状态，绝不跨群混合风格、热梗或示例。

## 2. 发送者匿名化与敏感信息脱敏

- **匿名化发送者 ID**：入库时对 `(group_id, raw_sender_id)` 使用 SHA-256 单向加盐哈希生成 `pseudonymous_sender_id`（仅用于单成员采样均衡与独立成员数统计，不暴露真实 QQ 号/OpenID）。
- **前置脱敏**：浏览器端导入预览阶段及后端 `cleaner.ts` 双重执行正则脱敏，覆盖：
  - 手机号、邮箱、身份证号、银行卡号、QQ/微信号联系方式；
  - API Key / Token / Bearer / 密码字段（`password=`、`sk-`、`ghp_` 等）；
  - 精确住址模式与管理员自定义 `blocked_keywords`。
- **提示词注入隔离**：所有群聊文本、导入语料与模型蒸馏结果均视为不可信数据。检测到系统提示词覆盖、越权指令、工具调用伪造标记时自动拒绝入库；蒸馏输出经过严格白名单字段 Schema 校验，禁止生成任意系统规则。

## 3. 成员退出与彻底删除闭环（含防回滚复活）

当成员执行 `/social privacy off` 或 `/social forgetme`，或管理员在后台删除指定语料/成员数据时：
1. **立即停止采集**：在线采集器实时检查 `{member_privacy}.opt_out`。
2. **级联清理派生数据**：
   - 删除 `{learning_corpus}` 中匹配该成员/语料的记录；
   - 删除 `{dialogue_examples}` 中 `source_corpus_ids` 引用已删语料的样本；
   - 重新校验 `{group_memes}` 中引用已删语料的证据计数，证据不足则降级为 `inactive`；
   - 将受影响的旧历史/候选 `{style_profiles}` 版本标记为 `invalidated`（包含 `contains_deleted_data = 1`），并立即失效内存编译缓存。
3. **防回滚复活**：版本回滚接口强制检查目标历史版本是否处于 `invalidated` 或引用了已删除语料/已退出成员；若命中则拒绝回滚并提示重新基于当前合规语料蒸馏。

## 4. 严禁越权边界

学习系统**绝不能**自主修改：安全规则、系统权限、工具白名单、管理员配置、基础人格、API Key、源代码或数据保留规则。
