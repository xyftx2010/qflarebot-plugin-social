# QFlareBot Social V0.12.0 — 数据库迁移与存储设计（Migration v6）

## 1. 现状核实

当前 [schema.ts](file:///e:/qflarebot-plugin-social/src/store/schema.ts) 已包含 5 个迁移版本：
- v1：`v0.1.0_base_social_memory`
- v2：`v0.5.0_multimodal_vision_and_memes`
- v3：`v0.10.0_ai_voice`
- v4：`v0.11.0_social_agent`
- v5：`v0.11.1_adaptive_routing`

因此 V0.12.0 无损新增 **Migration v6：`v0.12.0_style_learning_system`**。所有语句使用 `CREATE TABLE IF NOT EXISTS` / `CREATE INDEX IF NOT EXISTS`、`{占位符}` 表名与索引名、非整数主键统一 `WITHOUT ROWID`，不修改任何历史表结构。

## 2. 物理表设计（合并高内聚逻辑表，避免过度拆分）

为兼顾可追溯性与 D1 免费版查询/写入配额，将 15 个逻辑模块合并为 **10 张清晰的高内聚物理表**（全部包含 `group_id` 或群级作用域）：

| 物理表 | 对应逻辑模块 | 主键与核心索引 |
| --- | --- | --- |
| `{learning_group_settings}` | 群级学习授权、冻结长期风格、单群权重覆盖 | `PRIMARY KEY (group_id)` |
| `{learning_sources}` | `learning_sources`（导入批次、授权范围、进度、状态） | `PRIMARY KEY (source_id)`，索引 `(group_id, created_at)` |
| `{learning_corpus}` | `learning_corpus`（统一标准化语料，默认 30 天 TTL） | `PRIMARY KEY (corpus_id)`，索引 `(group_id, learning_status, timestamp)`、`(group_id, content_hash)`、`(group_id, pseudonymous_sender_id)` |
| `{learning_jobs}` | `learning_jobs` + `learning_checkpoints`（租约锁、检查点、重试、预算） | `PRIMARY KEY (job_id)`，索引 `(group_id, status, updated_at)` |
| `{style_profiles}` | `style_profiles` + `style_features` + `dialogue_behaviors` + `learning_evidence`（版本化 JSON 档案 + 溯源 `source_corpus_ids_json`） | `PRIMARY KEY (profile_id)`，索引 `(group_id, status, version)` |
| `{group_memes}` | `group_memes`（群内热梗知识库，含状态、证据、独立发言人数、衰减权重） | `PRIMARY KEY (meme_id)`，索引 `(group_id, status, popularity_weight)` |
| `{dialogue_examples}` | `dialogue_examples`（高质量对话样本，含 CJK 检索词、标签、行为、来源 IDs、TTL） | `PRIMARY KEY (example_id)`，索引 `(group_id, status, quality_score)` |
| `{learning_feedback}` | `learning_feedback` + `learning_evaluations`（独立评估集，绝不回流语料库） | `PRIMARY KEY (feedback_id)`，索引 `(group_id, created_at)` |
| `{learning_usage_stats}` | `learning_usage_stats`（按日统计学习调用次数、Token、估算成本） | `PRIMARY KEY (day)` |
| `{learning_audit_logs}` | `learning_audit_logs` + `learning_exclusions`（审计日志与语料/词条排除） | `PRIMARY KEY (id)`，索引 `(group_id, created_at)` |

> 成员退出状态直接复用已有 `{member_privacy}`（`/social privacy off`），同时在 `{learning_exclusions}` 额外支持按匿名 ID 或特定语料 ID 排除，不重复造轮子。

## 3. 回滚与降级策略

1. **功能级秒级回滚**：将 `style_learning_enabled` 设为 `false`，或将指定群在后台「风格档案」中回滚到上一稳定版本 / 停用当前版本，聊天引擎立即恢复基础人格 + 长期记忆运行。
2. **数据级无损迁移**：v6 仅追加新表，不改写 v1–v5 任何既有表；如需彻底清理学习数据，可在后台执行「清除本群全部学习数据」，清空该群在全部 10 张学习表中的记录并失效缓存。
