# V0.11.0 源码审查、功能差距与平滑迁移报告

## 1. 前置源码审查结论

- **原有依赖检查**：`v0.10.0` 及以前版本在 `depends` 中声明了 `agent: 'optional'`，并通过 `yield_at_to_agent` 与原生 `qflarebot-plugin-agent` 规避 `@机器人` 重复回复。
- **V0.11.0 独立化变更**：
  - 移除 `depends.agent`，改为 `depends: { llm: '*', 'core.tools': 'optional' }`，彻底消除对原生 `agent` 插件的运行时依赖。
  - 在 `qflarebot-plugin-social` 内建立统一的 Social Agent Engine（快通道 + ReAct 工具循环），并对外导出兼容的 `services.agent`（`registerPrompt / disablePrompt / clearPrompt / listPrompts`），不重复实现已弃用的 `registerTool`。
  - 全部能力基于 D1 + R2，**保持 0 Durable Object**，不损失 QFlareBot 预览 URL 健康检查与隔离安全阀。

## 2. 原生 Agent 与 Social 能力对照

| 能力 | 原生 `qflarebot-plugin-agent` | `qflarebot-plugin-social` v0.11.0 | 说明 |
| --- | --- | --- | --- |
| 群聊自然对话与人格 | 支持（绑定 DO） | ✅ 统一引擎 + 群级人格 | 保留全部已有拟人人格与风格 |
| 短期上下文与压缩 | DO 历史压缩 | ✅ D1 滑窗 + `context_max_tokens` 自动压缩 | 0 DO 开销 |
| 长期记忆与隐私 | 会话记忆 | ✅ 群级隔离 + TTL + 敏感脱敏 + `/forgetme` + Opt-out | 不破坏既有 `{group_memories}` |
| 多模态看图/表情包/原生语音 | 仅看图 | ✅ 看图 + 表情包库 + 千问/MiniMax/OpenAI 原生语音 | 统一出口、互斥不重复回复 |
| Function Calling + `core.tools` | 支持 | ✅ 内置 8 工具 + `core.tools` 白名单 + 附件交付 | 严格遵循 `capture/list/describe/invoke` |
| 外部插件 `registerPrompt` | `services.agent` | ✅ 兼容导出 `services.agent` | 稳定排序保护前缀缓存 |
| 跨分钟定时提醒（cron+DO） | 支持 | 非本项目目标（专注群聊互动） | 若需定时提醒可保留原生 Agent 或独立课表/提醒插件 |

## 3. 原生 Agent 数据保护与可选迁移策略

- **绝不删除原生 Agent 历史数据**：停用原生 `qflarebot-plugin-agent` 插件时，其 D1 表（`p_agent_*`）与配置默认保留，不会因切换 `social` 而丢失。
- **不盲目合并两套聊天历史**：原生 Agent 的工具型历史记录与 Social 的拟人闲聊语境不同，建议新对话直接由 Social 自然积累。
- **如需保留原生 Agent 中的自定义人格或提示词**：
  1. 切换前先在面板导出或备份当前配置与原生 Agent 人格文本；
  2. 将需要保留的人格复制到 `social` 插件配置的 `custom_personas`；
  3. 在 `social` 管理页「工具中心」勾选需要放行的外部 `core.tools` 插件工具。

## 4. 灰度切换与回滚方案

1. **灰度验证**：先在单个测试群的「插件 → agent → 生效的群（除了这些群）」排除测试群，确保 `social` 的 `yield_at_to_agent` 为关闭状态，在测试群完整验收 `@机器人`、`/ask`、工具调用、看图、表情包与语音回复。
2. **正式停用**：确认全部 15 项验收标准通过后，由管理员在面板停用原生 `qflarebot-plugin-agent`（不勾选清除数据）。
3. **秒级回滚**：如发现任何异常，在面板重新开启 `qflarebot-plugin-agent` 并将 `social` 的 `yield_at_to_agent` 临时打开即可无损回滚。
